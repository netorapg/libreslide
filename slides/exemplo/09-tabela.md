kicker: tabelas
title: Atalhos de teclado
---

| Tecla            | Ação                          |
| ---------------- | ----------------------------- |
| `→` `Espaço`     | Próximo slide / próxima etapa |
| `←`              | Voltar                        |
| `O` ou `Esc`     | Visão geral de todos os slides |
| `F`              | Tela cheia                    |
| `N`              | Notas do apresentador         |
| `Ctrl` + `P`     | Exportar para PDF             |
